**2. Direct quotes of the criteria found.**
- Debus AR-2005 Definitions 1–4 (adapting Walter & Lecourtier): *"Two contact state models A and B … are distinguishable if, for almost any sensor path s(t) of sufficient length, there is no solution for the parameter set {p,q} such that the contact models are satisfied simultaneously."* / *"Contact model A … is globally identifiable if … there exists a unique solution for p … If there are a finite number of solutions then contact model A … is locally identifiable."* / *"A contact state model A is identifiable if and only if, given any p̂ and any s0, there is a unique solution to (11), which is p = p̂. If a finite number of solutions for p exist then A is locally identifiable. A is unidentifiable if an infinite number of solutions exist."* The test is **Taylor-series coefficient equality / solution counting** (eqs. (10)–(11)), *"based on finding practical … Taylor series"*, and is deliberately **global-analytic**, done *"during the design phase"*.
- Same paper, on the rank-type alternative they do **not** use: *"analysis of the Jacobian matrix singular values [11, 12] or condition number [5] can be used as local tests for identifiability. A model is unidentifiable if the parameter Jacobian is singular (i.e., high condition number) and a model is locally identifiable if the Jacobian is far from a singularity (i.e., a condition number less than 100 [5])."* (That is the robot-calibration rank/conditioning criterion, cited, not their own.)
- Jia thesis §7.2/8.2.1 (rolling on a plane): *"the observability rank condition"* is invoked — *"The use of controls was merely to avoid the technical difficulty in establishing the observability rank condition from repeated Lie derivatives of the output…"*; Theorem 32: *"The rolling system (7.17) is locally observable except for at most one object shape β if det(b1, b2, β) ≠ 0 and β·(Iz) ≠ 0 … κ1x^T D^-1 x ≠ κ2 y^T D^-1 y or x^T D^-1 y ≠ 0 …"*, with output = *"the contact location in the plane"* detected by *"a tactile array sensor embedded in the plane"*. Jia also has a rank statement elsewhere (Coulomb forward dynamics: *"unique solution if the … system Jacobian matrix has full column rank"*), a different object.

**3. Answers.** (Q1) **No rank/Fisher/observability condition by Debus & Dupont** — theirs is structural (Taylor-coefficient uniqueness, finite vs infinite solution count); they merely *cite* the Jacobian singular-value/condition-number local test (calibration literature, cond. <100) as the numerical alternative. **Jia & Erdmann do state an observability-rank-type condition** (spanning of cotangent spaces / Lie-derivative "observability rank condition", Theorem 32), but for rolling pose/motion, not for a contact-state catalogue. (Q2) **All point/point-wrench observations.** Debus IJRR-2004: *"Using only position sensing, the contact state sequence is successfully estimated…"*, explicitly *"The exclusion of force/torque sensing…"* — a serial manipulator, one pose reading per sample; no sensor-surface/depth field. Jia: single contact-point trajectory from an embedded tactile array — a *point* output, not a distributed penetration map. No paper in this set uses thousands of scalar depth readings over a sensor surface. (Q3) **Only discrete/structural identifiability of a finite catalogue**, matching contacts pairwise and parameters per model. **No Cramér-Rao bound, no covariance bound, no error bound.** Debus IJRR-2004 uses a *"k × k covariance matrix"* only as the HMM/MME innovation covariance for the goodness-of-fit likelihood, and *"…determine the values of the covariance matrix U"* empirically; no estimator-variance theory. (Q4) **No.** Nothing found stating that a planar half-space contact leaves in-plane translation unidentifiable. Their closest notions are degeneracies of *distinguishability* between two catalogue states (e.g. Example 4: *"making the two contacts indistinguishable"* if the object rotation angle is unknown) and Jia's *"Rotation about the Contact Normal"* / non-observability for degenerate shapes *"such as a sphere"* — a **shape** degeneracy of a moving-contact system, not a **gauge freedom of the contact plane** and not a tangential-position gauge. (Q5) **No.** No equation anywhere here for the covariance of a fitted contact plane from tactile/range data; Jia gives an observability *rank* condition, Debus gives solution counts, Debus-IJRR gives an empirical innovation covariance.

**4. VERDICT: Partly — the mathematical *phenomenon* (rank deficiency / unobservable directions) is classical and appears in this literature, but our specific result is NOT covered.** Covered: (i) "identifiability is a rank/null-space question" is explicitly acknowledged (the cited Jacobian-singularity test, cond. <100); (ii) Jia & Erdmann already own an *observability rank condition* for contact-based state estimation, so we cannot claim "first observability-rank analysis in contact sensing"; (iii) Debus/Dupont own the criterion "a parameter is unidentifiable iff infinitely many parameter values reproduce the same measurements", which is the qualitative ancestor of our gauge statement. **Not covered:** every criterion in these five papers is *structural/discrete* over a finite contact-state + parameter catalogue with **point** (pose or wrench/twist) observations; none has a **measurement-space Jacobian/Fisher information matrix of a distributed depth/penetration map**, none states **rank = 3 for a plane under a 5-DOF parameterisation**, none identifies **the 2-D tangential contact-point translation as the null direction of that map**, and none gives a **bound/resolution law** (Cramér-Rao, covariance, sensor-density scaling). Defensible novelty: the *distributed-map Fisher rank statement + the explicitly named tangential gauge for half-space contact + the resolution-invariance of the resulting rank/scale law*, framed as "the classical identifiability question re-posed for dense tactile maps"; that framing must cite the AR-2005 criterion and Jia's observability rank condition as ancestors, not claim the vocabulary as new.
