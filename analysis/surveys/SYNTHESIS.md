# 触觉 × 操作：开放面调研汇总（2026-09-30）

六路并行调研的结果。目标：找出**未被占据**且有**机制内容**的方向，避免重复劳动。
（`estimation_control` / `safety_monitoring` 两路见文末状态。）

## 一、总体结论：**机制级表面已基本饱和**

| 表面 | 状态 | 证据 |
|---|---|---|
| 触觉如何进入**动作接口**（执行长度/残差/WAM/快内环/事件→动作） | 🔴 **饱和** | 执行长度信号 **12 种已占**且**无一篇用触觉**；触觉残差修正 **8+ 篇**；触觉世界动作模型 **9-12 篇**；慢-快内环 **4+ 篇** |
| **统一触觉表征** | 🔴 饱和（按手索引那套） | ME-Dex / FTP-1 / T3 / UniTacHand / TactAlign / UniForce / GenForce / Sparse-X / CTSRL / AnyTouch2… |
| **感官预测目标**（预测未来触觉） | 🔴 饱和 + **领域自证弱杠杆** | 12 篇；TacPAC 预测单独只拿回 ~1/3；Tactile-WAM 朴素触觉 1.3% < 纯RGB 5.8%；Compact VT-WM"准确预测未必改善控制" |
| **监测器度量层**（标定/提前量/逐具身/漂移鲁棒） | 🟢 **无人认领** | 见第四节 |
| **跨具身 held-out 零样本** | 🟢 ~85% 空 | DexGrasp-Zero 做 held-out 手但**无触觉** |
| **接触系（gauge）规范化** | 🟢 表面未占 | 所有统一表征都是**按手索引**，无一是**按接触索引** |

**已被占据的具体机制（不要进）**：用任意便宜的非触觉置信信号选执行长度（12 篇）；触觉/力残差修正冻结 VLA（8 篇）；预测未来触觉隐变量/图像（12 篇）；慢策略+快触觉内环加权（4 篇）；触觉差异→重规划（HiTac-WAM）；接触事件→任务分阶段（N0-TWAM）；力签名→恢复菜单（FORGE-plus）；相位→块路由（TRACT）。
**假阳性率(FAR)** 已是监测器子领域标准（PATCH、ContactGuard），**不再算贡献**。

## 三、我的排序与理由

### ⭐ 首选：O6 可辨识性受限的接触估计 + 可认证的接触控制

**这是四路调研里唯一同时满足"有理论内容"与"能跑过基线"的方向。**

| 要素 | 内容 |
|---|---|
| **理论** | 分布式触觉映射下的**模式相关 Fisher 信息 / 混合可观测性秩条件**；接触几何+模式的 **CRB**；**充分性定理**（最小充分触觉统计量）；**覆盖→不变性引理**（集值估计器 + Lipschitz 控制器 ⇒ 接触不变式概率前向不变） |
| **对手** | 只有经验成功率；**RSS 2026 的形式化保证里没有任何传感** —— 我们补上传感 |
| **不重复** | 应用层（执行长度/残差/WAM/快内环）**全在**，**理论层空**；与那 40+ 篇完全不同层 |
| **把已有工作变成资产** | 我们反复测到的"学习模型打不赢一行统计量"，成为**充分性定理的预言**（调研确认无人发表过此观察） |
| **最大先例风险** | 经典接触形成可观测性 / 贝叶斯混合模型状态估计（Gadeyne IJRR05、Lefebvre IJRR05、Debus&Dupont、Koval ISRR13、Jia&Erdmann）。**防御**：经典假设已知有限构型目录 + 点力旋量观测，且**不给任何界或覆盖保证**；我们的增量是**分辨率相关秩亏 + CRB + 充分性 + 覆盖**。**最有力的回答：把 Debus 的 HMM 复现为本定理的特例** |
| **代价** | **真数学**（非平凡的 CRB 与充分性定理）；要复现经典特例；认证控制器需真机或精心设计的仿真 |

**第一步（最小可证伪的理论骨架）**：在**简化但非平凡**的设定下，用 12 只手的实际位点几何算出
**接触状态（位置 + 法向）的 Fisher 信息与秩**，给出"何时可辨识、何时秩亏"的条件，
并检验它与我们已测到的现象一致（如：位点数 8→10、布局变化如何改变可辨识性）。
这是**可计算**的，且与剩下的调研无关。

### 其余排序（保留）

**2️⃣ O3（度量层）—— 确定开放且马上能做，但上限是度量/负结果型**
- 12 手数据在盘上、inv/equi 套件是 benchmark 自带、标定/提前量离线可算
- 但你已明确不要"发不了大文章"的那类

**3️⃣ O2（接触系 gauge）—— 理论强、协议硬，但必须真机**
- 仿真里 **无"held-out 传感器"轴**（13 个 robot_key 共用同一传感器模型）
- 真机的异手型 + 异传感器是我们唯一的不对称优势

**4️⃣ O1（接触事件锚定分块）—— 可立即实施，但存活条件苛刻**
- 必须只在**运动学不可见**跃迁上验证 + 主指标换成**事件时序精度**，否则会被判成"PACE 加传感器"

**5️⃣ O4（outcome-margin 世界模型）—— 立意好、成本最高（17 小时反事实数据）+ 三篇邻接先例**

**6️⃣ O5** —— 可作为 O2/O6 的配套，不单独成篇

## 四、数据质量与评审口径（可用的额外材料）

- **数据缺陷**：TLabel 之所以存在，是因为触觉数据缺统一标注与质检（已报 `phase_skip` 类标签错误）；HRDexDB 有 2/4 具身**完全缺触觉**。**没有任何已发布数据集被记录为"已完全核验"**。
- **审稿人口径**：NeurIPS checklist 第 7 条（误差棒与方差定义）、Vincent et al. 2405.05439（预算感知的 CDF 下界）、可复现性元数据作为一条评测轴。
- **Bench2Dex 触觉的物理含义**是几何穿透深度，**不是力/剪切** —— 主张不能越界成"测量了力"。

## 五、已确认的开放（供交叉验证）

- 所有统一触觉表征**按手索引**，无一是**按接触索引**
- 无一篇报告**真正 held-out 手型的零样本触觉迁移**
- 无任何触觉 benchmark 定义**标定度量**；**提前量**从不被扫描/报告
- 策略世界的 **inv/equi 漂移套件从未指向过监测器**
