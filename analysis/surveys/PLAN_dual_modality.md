## 2. 科学问题

> **同一个指尖上的两个传感器，在同一个物理交互中，各自能"知道"什么？**

## 3. 理论如何给出可证伪预言

每种模态定义自己的**不可区分关系**（观测分布相等）：
```
~力   : 净力相同 → 不可区分（每指 3–6 个数）
~阵列 : 深度分布相同 → 不可区分（每指数千个数）
~力 比 ~阵列 粗  ⇒  存在【阵列可监测、力原理上不可】的结局
```
可计算：对每种模态写测量 Jacobian，算**可辨识子空间**与 CRB（沿用 theory/ 的 T1–T3 机器）。

## 4. 判决性对照（本硬件独有）

> **匹配净力，改变力的分布。**
> - 力通道：按构造看不到差别 → **AUC ≈ 0.5**
> - 阵列通道：看得到 → **AUC ≈ 1.0**

**该 0.5 是【物理构造】的，不是统计得到的** ⇒ 无法用噪声/样本量质疑。
**且只有共址传感器能做该对照**（他人的力与阵列在**不同指尖**，匹配不了）。

## 5. 三项贡献（对应文献缺失的四项）

```
C1 首次【真机、同接触、同时双模态】的任务级模态对照（消掉跨硬件混淆）
C2 匹配净力的物理对照：力通道按构造停在 0.5，阵列通道显著更高
C3 用可辨识性理论【预言】每种模态能监测什么（而非仅事后描述）
   + 量化文献里的"模态差距"中有多少来自传感器混淆
```

## 6. 结局标签（按强度）

```
① 分布条件本身（合成）              —— 只证明现象，最弱
② 真实任务结局（成败）              —— 有说服力
③ ★ 真实结局中【力失败、阵列成功】的那一类 —— 最强，且是理论【要求存在】的
```

## 7. 第一步先导（判生死）

```
采一小批数据（几十分钟量级）:
  1. 同一物体、同一任务，用不同手指组合执行（1指/2指/3指）
     → 净力可匹配、分布不同
  2. 每指尖同时记录: 三维力 + 阵列图 + 结局标签
  3. 离线: 力通道监测 AUC  vs  阵列通道监测 AUC
预言: 力 ≈ 0.5（匹配后），阵列显著更高
```
