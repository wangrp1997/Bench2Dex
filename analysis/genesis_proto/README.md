## 关键设计（P5）

```
一个策略 + 一个触觉预测器，三种路由:
  none : 动作头只看 [本体感觉, 触觉]
  aux  : 同上，外加预测器的辅助损失（预测器【不】进动作头）
  test : 预测器的输出【拼进】动作头输入
两种预测目标:
  raw  : 预测【未来触觉向量】(96 维)
  task : 预测【未来接触力】(1 维，正是奖励关心的量)
```

**可证伪的预言**：`test/raw` 最差（复现文献的负结果）；`aux/*` 好；`aux/task` 最好。
若 `aux/raw ≈ aux/task` ⇒ "预测任务泛函更好"这个想法没价值 ⇒ 止损。
