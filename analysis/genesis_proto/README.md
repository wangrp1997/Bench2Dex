## 关键设计（P5）

```
一个策略 + 一个触觉预测器，三种路由:
  none : 动作头只看 [本体感觉, 触觉]
  aux  : 同上，外加预测器的辅助损失（预测器【不】进动作头）
  test : 预测器的输出【拼进】动作头输入
两种预测目标:
  raw  : 预测【未来触觉向量】(96 维)
  task : 预测【未来接触力】(1 维，正是奖励关心的量)
```

**可证伪的预言**：`test/raw` 最差（复现文献的负结果）；`aux/*` 好；`aux/task` 最好。
若 `aux/raw ≈ aux/task` ⇒ "预测任务泛函更好"这个想法没价值 ⇒ 止损。

## 关键突破：探针读数的根因

```
症状: 无论把物体推多深，触觉读数恒为 0
根因: 物体用了 fixed=True（运动学体）⇒ SDF/raycast 探针查询【看不到它】
修法: 物体必须是【动态】刚体；仍然每步 set_pos 指定高度 ⇒ 既可控又可见

验证（动态物体 + 每步 set_pos）:
  设定z偏移(mm)  实际z     depth_max   |F|sum
      +4         0.0305    0.00845     0.1353
       0         0.0276    0.01142     0.1826
      -4         0.0246    0.01438     0.2125      ← 单调 ✓
```

## 任务最终形态（PadForceEnv）

```
固定平台 + 上表面 6×6 探针（法向朝上，官方 tactile_sandbox 的布局）
动态物体，智能体每步设定其高度（±5mm）
目标力每集随机化（±40%）⇒ 策略【必须靠触觉】读当前力并闭环调节
奖励 = -(1 - exp(-|F - F_target|))，有界于 (-1, 0]

标定（F_TARGET=8.0）:
   action  -1.00  -0.20   0.00   0.60   1.00
   |F|sum   3.54   7.31   8.39  11.90  15.36
   reward  -0.99  -0.50  -0.32  -0.98  -1.00
   ⇒ 单调 + 最优在【内部】+ 梯度强 ✓ 任务良定义
```

## 第二轮 bug 与结论（因子实验 v2/v3）

```
bug 21: critic 拿到拼接后的 129 维输入（h 被重新赋值）⇒ test 路由全部崩溃
        "mat1 and mat2 shapes cannot be multiplied (1x129 and 128x1)"
bug 22: 预测器 pred(x) 走【独立分支】、不共享编码器
        ⇒ route=aux 的辅助损失训练了一个与策略无关的网络
        ⇒ aux 的结果与 none 【逐位完全相同】（这就是发现它的线索）
        修法: pred(h)，吃编码器输出
bug 23: 目标随机化只有 ±40% ⇒ 常数动作≈0 已接近最优 ⇒ 无学习空间
        修法: 目标在 [4.5, 14.5] 上随机（几乎整个可达量程）

v2 结果（120 轮，修好后）:
  none/raw -0.672 | aux/raw -0.681 | test/raw -0.717
  none/task -0.703 | aux/task -0.762 | test/task -0.752
  方向: test < none ✓ 与"喂预测触觉给动作分支有害"一致
  但:   task < raw ✗ 与我们的假设相反
  且:   全部远差于逐集最优 (-0.15) ⇒ 【欠训练，比较无意义】

收敛检查（600 轮, none/raw）: -0.786 → -0.295（波动 -0.30~-0.72）✓ 确实在学
⇒ v3: 600 轮 × 5 种子 = 30 格子

## v3 结果（600 轮 × 5 种子 = 30 格子）：**假设被否定**

```
route  target   n     平均      标准差
none   raw      5   -0.5223   0.1924
none   task     5   -0.4580   0.1490
aux    raw      5   -0.6165   0.2449
aux    task     5   -0.6933   0.1499
test   raw      5   -0.4250   0.1092     ★ 最好
test   task     5   -0.6803   0.1226

参考: 随机策略 ≈ -0.80 ; 逐集最优 ≈ -0.15
```

**假设（由 survey6 的矛盾调研提出）**
```
不是"预测有害"，而是【信息路由】:
  (i)  预测作【仅训练监督】(aux)   → 应中性/有益
  (ii) 动作分支在【测试时】读预测 (test) → 应有害
  (iii) 用想象 rollout 做规划      → 应有害
```

**数据判定**
```
❌ test/raw 最好（-0.425），不是最差 —— 与 (ii) 相反
❌ aux 最差（-0.617 / -0.693） —— 与 (i) 相反
❌ 全部差异在噪声内（n=5, std 0.11-0.24）
⇒ 【假设在本设定下未被支持】
```

**保留意见（诚实）**
```
· 本任务是【玩具级】：1 维力调节、无灵巧手、单点接触
  ⇒ 结论只在本设定下成立，不能推广到 TacWAM 那类完整系统
· 但方向相反 + 不显著，两条合起来，【不值得再投入】
· 与今天的其他负结果一致: S5 显示低维力通道胜过高维触觉；
  理论线的 5 个"首次"是经典的；传感器设计空间被 Tactile Genesis 占据
```

**结论：A 路线（信息路由原型）没有产出可发表的正面结果。**
