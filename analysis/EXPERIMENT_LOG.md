## T1：分布式触觉映射下的可辨识性秩

**目的**：在真实传感面几何下，算出"接触状态（位置+法向，5 DOF）"中有多少是可辨识的。

**方法**
- 测量模型：刚体**平面接触**（半空间）。物体位于 $\{x:(x-p)\cdot n\ge 0\}$，
  传感面上点 $x_j$ 的穿透深度 $h_j=\max(0,(x_j-p)\cdot n)$，接触状态 $\theta=(p,n)$。
- Jacobian：$\partial h_j/\partial p=-n$，$\partial h_j/\partial n=+(x_j-p)$ 在 $n$ 的切空间投影。
- Fisher 信息 $F=\frac{1}{\sigma^2}\sum_{j:h_j>0} g_jg_j^\top\in\mathbb{R}^{5\times5}$，秩 ⇒ 局部可辨识维数。
- 几何来源：`/mnt/public/datasets/bench2dex/dex2bench_dataset/Robots_p/<hand>/tactile_sensor/*_point.npy` 与 `*_normal.npy`（每面 (240,240,3)）。
- 探针：3 个接触法向 × 2 个深度 × 每面。

**命令**
```
python theory/t1_identifiability.py    # 结果写 theory/t1_results.json
```

**结果**（74 个传感面，444 次探针）
```
FIM 秩分布: {1: 95, 2: 194, 3: 155}      ← 最大秩 3，而 θ 有 5 个自由度
接触点数范围: [1, 57600]，中位 23
条件数范围: 1.05e13 ~ 1.63e19
```

**结论**
1. **接触点的切向位置在原理上不可观测**：观测只依赖接触**平面**（2 姿态 + 1 偏置 = 3 DOF），
   与传感器分辨率无关。
2. **可辨识维数随"接触斑 / 采样密度"增长**：1 点→秩1，13 点→秩2，≥3 个分布良好的点→秩3。
   ⇒ 可操作判据：**可辨识性由接触斑尺寸相对触觉采样决定，不是分辨率**。
3. **条件数 1e13–1e19**：即使可辨识的 3 个方向也极端病态。

**对我们已有负结果的解释**：接触量（点数/深度）永远是可观测量；接触几何不可辨识
⇒ 学习模型拿不到统计量之外的信息 ⇒ "学习式监测器打不赢接触统计量"是**推论**而非巧合。

**风险（已记录）**："平面只有 3 DOF"本身接近显然。真正的贡献必须落在
**①可辨识性跃迁**（平面→棱/曲面时秩上升）与**②量化 + 预言**（CRB 是否卡住实际监测器）。

## T2：平面模型是否成立 + CRB 是否紧（生死判据）

**目的**：T1 是秩的定性结论，且依赖"平面接触"假设。必须检验两件事：
- (a) **真实数据里的接触是不是平面**（若是，模型适用；若不是，必须扩展模型）
- (b) **估计误差是否被 CRB 卡住**（若是，理论有定量预测力 → 继续；若否，理论无意义 → 止损）

**方法（离线，用已有数据）**
- 数据：演示 HDF5 同时存有 `robot/tactile/tacmap/<site>`（8bit 量化图）与
  `robot/tactile/distance_along_normal_m/<site>`（**米制穿透深度场**）。
- 真值：从深度场按 T1 的模型**最小二乘拟合接触平面** $(n,d)$；残差大小 ⇒ 平面假设是否成立。
- 观测：8bit tacmap；按 T1 的模型做**最大似然**估计平面。
- 对比：估计误差 vs **CRB**（由几何 + 量化噪声给出）。
- 附加对照：一个小的学习式估计器（CNN）—— 若它也停在 CRB 附近，说明信息确实被几何/量化限死。

**判据**
- (a) 平面残差 ≪ 接触深度 → 平面模型成立
- (b) 估计误差 ≈ CRB（同一量级，不能被显著突破）→ 理论有预测力 → **继续**
- 若 (b) 被大幅突破 → 说明模型漏了信息 → **回炉或止损**

**命令**
```
python theory/t2_planarity_crb.py     # 结果写 theory/t2_results.json
```

**BUG 记录（重要，差点导致误判）**
第一版得到 `残差/深度 ≈ 578`（0.54 mm 深度给出 307 mm 残差）—— 物理上不可能。
**根因**：随包发布的传感面几何是**毫米**，而 `distance_along_normal_m` 是**米**，单位差 1e3。
修法：加载几何时 `× 1e-3`。
**影响**：T1 的**秩**结论不受影响（秩是尺度不变的），但 T1 报的**条件数**受尺度影响，已一并修正重算。
**教训**：这类量纲错误会伪装成"理论被证伪"。

**结果（单位修正后）**

(a) 平面假设：
```
site                     深度中位   平面残差RMS中位   残差/深度
left_pinky_elastomer      0.54mm       49.4um          0.092
left_ring_elastomer       1.83mm       92.8um          0.052
left_thumb_elastomer      3.88mm      338.4um          0.089
right_index_elastomer     1.29mm       31.2um          0.020
right_middle_elastomer    2.44mm       66.7um          0.028
right_ring_elastomer      2.83mm      129.0um          0.051
right_thumb_elastomer     5.47mm      575.7um          0.105
```
**残差/深度 = 0.020–0.105 → 真实接触确实近似为平面，T1 的测量模型成立** ✓

(b) CRB 定量检验（子采样接触点，看精度是否按 CRB 预测的规律损失）：
```
frac=1.00 k=2464  角度误差 0.000°  CRB 0.019°   d误差   0.0µm  CRB 4.4µm
frac=0.50 k=1232  角度误差 0.013°  CRB 0.027°   d误差   0.7µm  CRB 6.3µm
frac=0.25 k= 616  角度误差 0.044°  CRB 0.038°   d误差  15.9µm  CRB 9.0µm
```
**实测误差与 CRB 同量级，且随接触点减少同步增长** ✓

**结论（T2 = 生死判据）：通过**
1. **平面测量模型成立**（残差 2%–10.5% 的深度）
2. **CRB 有定量预测力**（同量级 + 同趋势）
⇒ **理论值得继续做**

**已知方法学缺陷（下一步修）**
- `frac=1.00` 那行误差为 0 是**自比较**造成的（子采样集 = 全集）
- 该检验度量的是"对接触点集的敏感性"，**不等于** CRB 的统计含义（噪声下的方差）
- **T3 应做正规检验**：用 **8bit 量化 tacmap** 做估计、用**全精度深度场**做参照，或注入已知噪声，
  直接测估计方差并与 CRB 对比

## T3：统计意义上的 CRB 检验（正规版）

**目的**：T2 测的是"对接触点集的敏感性"，不是噪声下的方差。这里做正规检验。

**过程中发现的两个 bug / 数据问题（都差点导致误判）**

**BUG-2 平面拟合方法错**：第一版用**无约束最小二乘 + 事后归一化**
（`(n,d) → (n/s, d/s)`）。但这**会改变预测值**（$X(n/s)-d/s \neq Xn-d$），所以那个估计器本身是错的。
**修法**：改用**总最小二乘**——超平面 $h=x\cdot n-d$ 在 $\mathbb{R}^4$ 中，
其法向 = 中心化数据 $[X,h]$ 的**最小奇异向量**。修后角度误差与 CRB 的相关性从 +0.16 升到 **+0.66**。

**🔴 数据发现（第 5 个数据集缺陷）：`tacmap` 与 `distance_along_normal_m` 不是同一个量**
```
拟合 u(tacmap) ≈ a·h(distance) + b:
  left_pinky   a=10.11  b=+282µm   残差RMS=369µm   相关 +0.98
  left_ring    a= 2.89  b=+3189µm  残差RMS=733µm   相关 +0.94
  right_index  a= 0.87  b=+4338µm  残差RMS=1902µm  相关 +0.35   ← 基本不相关
  right_thumb  a= 0.84  b=+6951µm  残差RMS=2242µm  相关 +0.63
```
斜率 0.5~10 乱跳、偏置 0.3~7.4 mm、残差 RMS 达 2 mm。
**⇒ 不能拿一个通道当另一个的参照**。任何把 `tacmap` 当深度代理的工作都建立在不可靠基础上。

**方法（自洽）**：自己把 `distance_along_normal_m` 量化成 8bit（`round(H/MAXD*255)/255*MAXD`）
来模拟传感器输出，估计平面并与 CRB 对比。

**命令**
```
python theory/t3_crb_quantised.py     # → theory/t3_results.json
```

**结果**（125 个接触帧，3 集演示；量化步长 58.8 µm，量化噪声 σ = 16.98 µm）
```
量        实测中位     CRB中位    实测/CRB
角度(°)    0.0039      0.0028      1.38
d(µm)       0.69        0.76       0.91
秩相关: 角度 +0.973    d +0.911
```

**结论（T3）：通过**
**估计误差基本落在 CRB 上（比值 0.91–1.38），且与 CRB 高度相关（+0.91 ~ +0.97）**
⇒ **测量模型与 CRB 都是正确的，且 CRB 紧、有定量预测力。**

**范围声明（重要）**：T3 是**自洽检验**——它验证的是**模型 + CRB**，
**不是真实传感器的 `tacmap`**（后者与深度场不一致，见上）。

## T4：可辨识性随物体曲率的跃迁

**假设**：半空间对面内平移不变（2 个规范自由度，不可观测）；曲面物体不是 → 横向位姿变为可辨识。
预期一个由曲率半径 R / 传感面尺度 ℓ 参数化的**跃迁**。

**方法**：物体 = 半径 R 的球，$h_j=\max(0,R-|x_j-c|)$，参数 $c\in\mathbb R^3$；
在**接触点局部系**内计算（全局系在大 R 时灾难性相消，第一版直接 `LinAlgError`），
用 Jacobian 的 **SVD** 求秩与 CRB，扫描 R，对随包发布的**全部 74 个传感面**统计。

**命令**
```
python theory/t4_curvature_transition.py   # → theory/t4_results.json
```

**结果**（跨面中位）
```
R/extent   切向CRB(中位)   秩(中位)
  0.77        3.0 µm         3
  1.92        5.7 µm         3
  3.84        9.9 µm         3
  38.42      92.7 µm         3
sharpa/4F (尺度32.8mm): R=1mm→2.2µm ; R=1000mm→86.3µm  (39×)
sharpa/TH (尺度37.8mm): R=1mm→2.8µm ; R=1000mm→116.5µm (42×)
```

**结论（T4）：假设被证伪 —— 没有秩跃迁，是一条光滑的精度律**
1. **秩恒为 3**：球体位姿始终可辨识。曲率改变的是**精度**而非可辨识维数：
   切向 CRB 随 $R/\ell$ 单调增长约 1–2 个数量级。
2. **更关键（且对我们不利）**：即使接近平面（$R/\ell=30$），切向 CRB 也只有 ~100 µm
   ⇒ **传感几何给出的位姿信息是充足的，从未到"无法辨识"**。

**对整体论断的修正（重要）**
原命题"可辨识性解释了为什么学习式监测器打不赢统计量"**站不住**：传感几何不是瓶颈。
真正的瓶颈是两个：
- **(a) 任务**：结局函数**是否依赖**可辨识的位姿自由度？若不依赖，秩统计量本就充分。
- **(b) 通道**：**实际传感器通道是否忠实携带这些信息**？
  ⇒ 这使得 **DATA-5（`tacmap` 与深度场不一致）从附带发现升级为核心问题**：
  若 `tacmap` 不忠实反映接触几何，则任何基于它的监测器受限于**通道保真度**，
  而不是传感几何或模型容量。

**下一步由此改写**：优先做 **T5′（通道保真度 → 监测能力）**，
而不是原来的"可辨识性 → 监测能力"。即：**量化 `tacmap` 相对深度场损失了多少接触几何信息，
并检验这个损失能否预测实测监测能力。**

## T5′：通道保真度 → 监测能力（修正后的关键验证）

**目的**：T4 排除了"传感几何"，那么剩下两个候选瓶颈——(a) 任务结构与 (b) **实际通道保真度**。
DATA-5 表明 `tacmap` 与 `distance_along_normal_m` 不是同一个量，所以 (b) 可疑。

**方法**：同一批 60 条 rollout（两通道都有），用**同一个编码器、同一批折、同一个回合级目标**，
只换输入通道，并各自配一个一行统计量：
```
tacmap-learned   26=0.310  32=0.213  73=0.203   mean=0.242
depth-learned    26=0.238  32=0.293  73=0.180   mean=0.237
tacmap-stat      26=0.964  32=0.773  73=0.703   mean=0.814
depth-stat       26=0.905  32=0.827  73=0.781   mean=0.838
```

**命令**
```
python theory/t5_channel_fidelity.py    # → theory/t5_results.json
```

**结论（T5′）：通道也不是瓶颈**
两个通道的**统计量几乎一样好**（0.814 vs 0.838，逐任务有涨有跌）
⇒ 换成全精度深度通道**不能**提升监测能力 ⇒ **排除通道保真度假说**。

**注（记录但不用作结论）**：两个学习臂 AUC≈0.24（**反向**，学成"接触越多越可能失败"）。
这是训练病理（20 集 + 回合级标签下的符号错误），与 EW 的结果不一致，本步结论**只看两个稳健的统计量臂**。

**由此得到的推论链**
```
(a) 传感几何/可辨识性  → T4 排除（信息一直充足）
(b) 通道保真度         → T5′ 排除（全精度深度 ≈ 8bit tacmap）
(c) ⇒ 剩下只能是【任务本身】：结局近似是"接触量"这个标量的函数
    → 一行统计量量的正是这个标量 → 统计量本质上是充分的
```

## T6：判别性实验 —— 结局依赖"关系"而非"量"

**目的**：理论（充分性那条腿）的**正面预言**：若结局依赖一个**一行统计量无法表达的关系**，
则量统计量应失效、关系感知监测器应胜出。构造：
$$\text{opposition}(t)=(\text{拇指在接触})\wedge(\ge1\text{ 非拇指位点在接触})$$
这是**关系型**的：5 个非拇指位点接触（无拇指）→ 量大但 opposition=0；
拇指+1 指 → 量小但 opposition=1。

**命令**
```
python theory/t6_relation_vs_amount.py   # → theory/t6_results.json
```

**结果**
```
task 26: L_amount 用量统计 1.000 | L_opp 用量统计 0.996   无opp时接触量中位=0.0  opp占比0.22
task 32: L_amount 用量统计 1.000 | L_opp 用量统计 0.986   无opp时接触量中位=0.0  opp占比0.06
task 73: L_amount 用量统计 1.000 | L_opp 用量统计 0.847   无opp时接触量中位=0.0  opp占比0.23
（真实失败：26 量0.964/opp1.000 ; 32 量0.773/opp0.660 ; 73 量0.688/opp0.828）
```

**结论（T6）：预期的判别【没有出现】**
**量统计量在关系型标签上也几乎全中**（0.996/0.986/0.847）。
原因：我设想的关键反例（"5 指接触但无拇指"）**在数据里几乎不存在**——
**无 opposition 时的接触量中位数普遍为 0.0**，即拇指不接触时手指通常也不接触，
**两个量高度混杂，无法解耦**。

⇒ **要制造判别性场景，需要一个"非对指性大面积接触"工况（如手掌/手指压在平面上但不含拇指），
而这 3 个任务里不存在。** 需要受控的新数据，不是现有数据能给的。

**弱信号（记录，不作结论）**：真实失败上 26/73 的 opposition 优于量，32 相反；
20 集下视为噪声。

## T7：标量是否（近似）充分？—— 更丰富的触觉描述能否超过它

**目的**：理论充分性那一条腿唯一**不需要新数据**就能检验的命题。

**方法**：回合级、**留一法**、60 条 rollout。三种描述同一段触觉流的方式：
```
f1 标量      : 全回合接触位点数的均值（一行统计量）
f2 计数直方图: 逐帧接触位点数的完整分布（8 桶）
f3 逐位点频率: 每个位点各自的接触频率（10 个数，"哪些位点"而非"几个"）
```
用逻辑回归（LOO）比 f2/f3 与 f1。

**命令**
```
python theory/t7_sufficiency_ceiling.py    # → theory/t7_results.json
```

**BUG-3（定论前抓到）**：`f1` 是**无向**原始统计量（`AUC(接触量→失败)=0.036`，
即用 `-量` 时是 0.964），而 f2/f3 的逻辑回归**自己学符号**。两者直接比不公平，
第一版因此报出 Δ=**+0.39/+0.52** 的假象。修法：统一取**有向 AUC** `max(a,1-a)`
（符号是一个任何人都免费学到的比特）。

**结果（有向 AUC）**
```
task 26: 标量0.964 | 直方图0.905(Δ-0.060) | 逐位点1.000(Δ+0.036)
task 32: 标量0.773 | 直方图0.627(Δ-0.147) | 逐位点0.520(Δ-0.253)
task 73: 标量0.688 | 直方图0.797(Δ+0.109) | 逐位点0.641(Δ-0.047)
平均 Δ:  直方图 -0.032   逐位点 -0.088
```

**结论（T7）：未能证伪充分性，但【未能证明】它 —— 功效不足**
- 更丰富的描述**没有系统性超过**标量（平均 Δ 为负；标量在 2/3 任务上最好）→ 与充分性一致
- **但每任务仅 20 集**，而我们自己测得**单次运行 AUC 波动可达 ±0.33** ⇒ Δ=±0.1 完全在噪声内
- 更丰富的特征还需**估计**（LOO 逻辑回归），小样本下对其**不公平**
- ⇒ **无法分辨小于约 0.2 的 AUC 差异。这是"未能证伪"，不是"已证明"。**

## T8：充分性上界的实例化（修正后的命题）

**背景（一次重要纠正）**：先前的"充分性 ⇒ 学习无用"**说得太强**。调研指出：
充分性给出的是 $\sup_f \mathrm{AUC}(f)=\mathrm{AUC}(P(Y|c))$，即 **c 的最优变换**，
而**不是** $\mathrm{AUC}(f)\le\mathrm{AUC}(c)$（对原始统计量）。若 $P(Y|c)$ 非单调（U 型风险），
学习模型可以**正当地**超过原始 $\mathrm{AUC}(c)$。
**正确说法**：没有模型能超过 **c 的似然比**，不是"没有模型能超过 c"。

**可检验预言**
```
P1  AUC(P(Y|c)) >= AUC(raw c)                    变换只会更好
P2  AUC(学习(全触觉)) <= AUC(P(Y|c))             学习不能在充分统计量之上再加东西  ← 新的判别性检验
P3  散度导出的上界  >= AUC(P(Y|c))
```

**命令**
```
python theory/t8_sufficiency_ceiling.py    # → theory/t8_results.json
```

**结果**
```
task 26  raw 0.964 | transform 0.952 | learned(rich) 0.988   P1✗ P2✗
task 32  raw 0.773 | transform 0.613 | learned(rich) 0.720   P1✗ P2✗
task 73  raw 0.688 | transform 0.578 | learned(rich) 0.531   P1✗ P2✓
pooled   raw 0.724 | transform 0.670 | learned(rich) 0.730   P2✗
```

**结论（T8）：不确定 —— 估计噪声淹没了要检验的效应**
**P1 也失败**（transform 比 raw 更差：0.952<0.964, 0.613<0.773, 0.578<0.688）
⇒ 这是**统计假象**：n=20 下估计出的变换不如"不做估计的单调排序"可靠。
⇒ **在现有数据规模下，"充分性上界"无法检验。** 需要更多 rollout，或一个无需估计的界。

## T9（2️⃣ 理论防御）：点测量极限 —— 证明 R1 严格推广经典结论

**目的**：经典接触可观测性（Debus & Dupont ICRA 2004；Jia & Erdmann 的 Montana 结构可观测性）
分析的是**点观测**（单接触、点力旋量）。我们的 R1 是**分布式面**。
要让 R1 成为**真正的推广**而非另一个问题，它必须在场坍缩为点读数时**退化为经典裁决**。

**预言**：$k$ 个接触采样点时，平面参数 $(n\in S^2,d)$ 的 FIM 秩 = $\min(3,k)$。
即 $k=1$ ⇒ 只有平面**偏置**可辨识（经典点观测情形）；$k\ge3$ ⇒ 整个平面可辨识。

**命令**
```
python theory/t9_point_limit.py    # → theory/t9_results.json
```

**结果**（sharpa/4F，活跃接触斑 6372 点，每 k 重复 8 次取中位）
```
k=1    秩=1   条件数 1.40e21   CRB_d=  16.97µm   CRB_n=0.0000°
k=2    秩=2   条件数 7.56e17   CRB_d=  21.57µm   CRB_n=0.0784°
k=3    秩=3   条件数 2.57e07   CRB_d=1149.89µm   CRB_n=2.5875°
k=4    秩=3   条件数 3.52e06
k=6    秩=3   条件数 5.14e05
k=10   秩=3   条件数 2.14e05
k=20   秩=3   条件数 1.83e05
k=40   秩=3   条件数 1.62e05
预言 秩 = min(3,k) 成立 ✓
```

**结论（T9）**
1. **秩 = min(3, 接触采样点数)** ⇒ **k=1（经典点观测）正是我们结论的 rank-1 角**
   ⇒ **R1 严格包含经典裁决为特例** ✓ 满足"必须退化"的防御要求
2. **从 k=2 到 k=3，条件数下降约 10 个数量级** —— 这是可辨识性从"勉强"到"完全"的实际跃迁
3. **反直觉但正确**：k=3 的 CRB_d（1149µm）**比 k=1（17µm）差** ——
   因为 k=1 时 d 被单点钉死，而 k=3 时 $(n,d)$ 联合估计并受 $(n,d)\to(n/s,d/s)$ **尺度规范**耦合。
   ⇒ **尺度规范是一个真实、可观测的效应**，而触觉文献从未命名它 ✓

**可写进论文的一句话陈述**：
> **可辨识维数 = min(3, 接触采样点数)；且从 2 点到 3 点，病态程度下降约 10 个数量级；
> 经典的点观测结论恰是 k=1 的角。**

## T13：Jia & Erdmann 原文核查（`papers/IJRR99.pdf`）★ 最重的一次主张修正

用户补充了 **`IJRR99.pdf` = Jia & Erdmann, "Pose and Motion from Contact"**（CMU，44 页，June 1998）。

**关键词命中**
```
observability ×36   rank condition ×5 ✓   gauge ×6   jacobian ×3   montana ×3   indistinguish ×2
【无 Fisher information / 无 Cramér-Rao / 无 covariance / 无 information matrix】✓
```

**原文（关键引文）**
> "Two states $x_1,x_2\in M$ are said to be **indistinguishable** (denoted $x_1 I x_2$) if for every
> admissible control $u$ the output functions $y(t,x_1,u)$ and $y(t,x_2,u)$, $t\ge0$ are identical on
> their common domain of definition. **The system is observable if $x_1 I x_2$ implies $x_1=x_2$.**
> … **Theorem 2 (Herman and Krener)** System (22) is locally observable at state $x_0\in M$ if
> $\dim d\mathcal O(x_0)=n$. The equation $\dim d\mathcal O(x_0)=n$ is called the
> **observability rank condition**."

**⇒ 修正（又一轮）**

| 我们的东西 | 修正后的判定 |
|---|---|
| 不可区分关系 $\sim_S$ | ❌ **经典**（Hermann–Krener 1977；**Jia & Erdmann 已在接触语境中明确定义**） |
| 定理 1（$J$ 可监测 ⟺ 类上常数） | ⚠️ **本质是经典可观测性框架应用于状态函数的推论**，非新定理 |
| 泛函可观测性 $z=Lx$ | ❌ 经典（Kravaris） |
| Fisher/CRB 机器 | ❌ 经典（Lefebvre 2005 式 10） |
| 雅可比条件数判局部可辨识性 | ❌ 经典（Debus & Dupont 2004） |
| 特定构型下参数不可观测 | ❌ 经典（Gadeyne 2005） |

**⇒ 先前"任务级 iff 定理未被找到"的结论【过于乐观】**：调研只检索字面表述，
而**数学内容已存在于 Hermann–Krener / Jia–Erdmann**。

**✅ 修正后仍然成立的独有部分**

| 还剩 | 为什么 |
|---|---|
| **随机传感器下的不可区分**（**观测分布**相等，而非确定性输出函数） | 经典为确定性输出函数；触觉是**有噪观测** |
| **定理 2（ε-可监测性界）** | ★ **经典框架是二值的，不给任何误差界** —— 定量版本是新的 |
| **与学习式监测器 / PAC-Bayes 的桥** | 经典从不涉及学习式监测器 |
| **稠密触觉图的 FIM 实例化**（散布矩阵、秩 = min(3,k)、两个显式规范、CRB 实测达成） | 经典**全是点观测、无界、无实测** |
| **k=2→3 条件数跳约 10 个数量级** | 新 |
| **受控解离实验（T11）** | ★ 实测证据，无人认领 |

**修正后的理论主张（第三次收窄）**
> 我们**不主张**新的可辨识性框架。**主张的是**：把该经典框架
> **(a) 推广到随机传感器**、**(b) 给出定量的 ε-版本与 FP/FN 界**、
> **(c) 实例化到稠密触觉深度图**（秩 = min(3,k)、显式规范、CRB 实测达成）、
> **(d) 用受控解离实验给出经验证据。**

**元观察**：T12+T13 两轮原文核查共砍掉 **5 个"首次"声明**
（Fisher/CRB、条件数判据、参数不可观测、可观测性秩条件、不可区分关系）。
**但每次砍完剩余的更硬**：唯一真正独有的是**定量版本 + 稠密图实例化 + 那个实验**。
**这是本轮最有价值的产出** —— 若未读原文，稿件会在评审第一轮被打掉。

## S2：匹配净力的判决性检验（**结论：实现不可靠，作废**）

**做法**：用受控变体 A/B，匹配"净力"后比较力通道与阵列通道能否区分两族。
**通过构造**得到的 0.5 本应免疫噪声质疑。

**命令**：`python theory/s2_matched_force.py` → `theory/s2_results.json`

**三轮尝试**
| 轮次 | 结果 | 问题 |
|---|---|---|
| 1 | 力幅值 0.5，但**力(学习) 0.88–0.98**、**阵列 0.50** | 只匹配了力**幅值**（标量），30 维力向量仍带分布信息 |
| 2 | 修 1（匹配完整向量）+ 阵列改 max-pool | 匹配集只有 n=25（A_k2/A_k3 仅 15–22） |
| 3 | 力向量残差 0.0%，但力(学习) 仍 0.889 | **逻辑自相矛盾** ⇒ 小样本 CV 不可信 |

**根因（结构性，非调参可解）**
> 仿真里"力"是阵列的**30 维投影** ⇒ "匹配力"= 匹配该投影；
> 而 761 帧里大部分是无接触帧，**能匹配且样本足够的对照集根本构造不出来**。

**结论**：**S2 作废**。早先"仿真更干净"的判断**错误**：
仿真里没有硬件混淆，但**也没有可匹配的物理量**，所以做不出判决性对照。
**判决性检验只能在真机上做。**
